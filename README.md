# sistem-panen-rajanabil
# Sistem Pencatatan Hasil Panen Digital

## Deskripsi

Program Python sederhana untuk menghitung total hasil panen
dan menghitung nilai setelah diskon.

## Cara Menjalankan

1. Pastikan Python 3 sudah terpasang.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Buka terminal.
4. Jalankan perintah:

python sistem_panen.py

## Fitur

- Menghitung total hasil panen.
- Menghitung nilai setelah diskon.
